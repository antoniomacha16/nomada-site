  • Materiais resistentes e impressão de alta qualidade

A NÓMADA nasceu de uma ideia simples: as frases que dizemos todos os dias — o humor, as manias, as expressões que nos definem — merecem sair da conversa e ganhar forma. Não é só para ti. É o presente certo para quem "é mesmo assim".

Cada coleção é uma edição limitada: quando esgota, estas capas nunca mais voltam a ser produzidas. Quem as tem, tem uma peça única.

Dúvidas

Perguntas frequentes

As capas estão sempre disponíveis?

Não, cada capa NÓMADA é uma edição limitada, pensada nos momentos do dia-a-dia. Quando esgota, nunca mais vai voltar a ser lançada. Se uma capa te conquistou, não esperes demasiado, depois de esgotar, já era.

Quanto tempo demora a entrega?

Cada capa é feita por encomenda, especialmente para ti. Entre produção e envio, recebes normalmente em 7 a 12 dias úteis. Enviamos para todo o país.

O material é resistente?

Sim. As capas têm uma qualidade acima da média com uma impressão de alta qualidade e proteção pensada para o dia-a-dia (quedas pequenas, riscos e uso diário). Elas são feitas para durar e para te fazer rir.

Como posso falar convosco?

Manda-nos um email para suporte.nomada.pt@gmail.com, respondemos o mais rápido possível. Dúvidas, trocas ou só para dizer olá, estamos cá. 🤍
